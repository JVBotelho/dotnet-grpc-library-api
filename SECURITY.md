# Security Policy

## Supported Versions

We actively support and patch the following versions of the project:

| Version | Supported |
| ------- | --------- |
| Main (v1.x) | :white_check_mark: |
| < 1.x   | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not** open a public issue. Instead, report it using one of the following methods:

1. **GitHub Private Vulnerability Reporting:**
   Go to the [Security tab](https://github.com/JVBotelho/dotnet-grpc-library-api/security) of the repository, click on **Vulnerability reporting**, and select **Report a vulnerability**. This allows you to privately disclose the issue to the maintainers.

2. **Email Security Contact:**
   If Private Vulnerability Reporting is unavailable, please email the maintainer directly at: `zmtsn3xg.refining218@passinbox.com` (or open a secure contact point).

We will acknowledge receipt of your report within 48 hours and provide a timeline for coordination and release of a fix.
